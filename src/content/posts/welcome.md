This is a sample article. Your public articles are built into **static HTML**, so normal readers do not query a database or CMS API.

## Why this architecture is fast

The public website is generated at build time and served as static assets. Dynamic server code is reserved for the private admin API.

## What to do next

Open the admin dashboard after Cloudflare Access and the GitHub write token are configured. Create your first real article, publish it, and then remove this sample.
